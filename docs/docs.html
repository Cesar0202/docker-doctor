1. Instalación

La forma más rápida, limpia y profesional de instalar Docker Doctor en cualquier servidor Linux o Mac es usando nuestro script de instalación. No requiere tener Go instalado:

curl -sSL https://raw.githubusercontent.com/Cesar0202/docker-doctor/main/install.sh | bash

También puedes compilarlo desde el código fuente usando go install github.com/Cesar0202/docker-doctor@latest si tienes un entorno de desarrollo Go configurado.

2. Uso de la CLI (Escaneo General)

Para obtener un diagnóstico rápido del estado de tus contenedores, redes, volúmenes e imágenes, ejecuta el comando principal. El motor evaluará métricas y te dará un Health Score sobre 100.

$ docker-doctor scan
Iniciando escaneo de Docker...
Docker Health Score: [Excelente] 97/100
Evaluando puertos locales y docker-compose.yml...

3. Asistente Proactivo (Fix)

Olvídate de buscar en Google cómo borrar contenedores detenidos o imágenes dangling. Docker Doctor detecta los problemas y te ofrece eliminarlos de forma interactiva y segura, calculando el ahorro exacto en Megabytes.

$ docker-doctor fix
Problema: Tienes imágenes colgantes (dangling).
Ahorro estimado: 1.2 GB
¿Deseas aplicar el comando [docker image prune -f]? (s/N): s

4. Experto en Errores (Explain)

Docker Doctor cuenta con una base de conocimiento para interpretar errores crípticos de Docker. Solo pégale el error y la IA estática te dirá qué significa y cómo resolverlo.

$ docker-doctor explain "no space left on device"
Diagnóstico: El disco duro donde Docker guarda sus datos está lleno.
Comandos útiles: docker system prune -a --volumes

5. Exportación y CI/CD

Docker Doctor es ideal para pipelines (Jenkins, GitHub Actions, GitLab CI). Puedes exportar los resultados del escaneo para guardarlos como artefactos o leerlos con otras herramientas usando los flags --output y --file.

# Exportar como reporte JSON para integraciones docker-doctor scan --output json --file report.json # Exportar como documento Markdown para Wikis docker-doctor scan --output md --file report.md # Generar una página HTML estática con los resultados docker-doctor scan --output html --file report.html
