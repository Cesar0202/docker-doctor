Health Score Matemático

Recibe una calificación de 0 a 100 basada en el estado de tus contenedores, imágenes huérfanas, seguridad y configuraciones.

🤖

Asistente Experto (Explain)

¿Error "Bind for 0.0.0.0:80 failed"? Docker Doctor interpreta los errores crípticos y te dice la causa exacta y el comando para arreglarlo.

✨

Reparación Interactiva (Fix)

No más comandos largos de limpieza. El comando interactivo escanea tu basura y te permite eliminarla con presionar "Y".

📈

Tendencias Históricas

Dibuja hermosas gráficas ASCII en tu propia terminal para ver cómo ha mejorado (o empeorado) la salud de tu entorno.

🔍

Detección de Conflictos

Escanea silenciosamente los puertos de tu sistema para avisarte de colisiones antes de que levantes un contenedor nuevo.

🖥️

Dashboard Web Local

Levanta una interfaz gráfica embebida súper minimalista con un solo comando para monitoreo en tiempo real.

Comienza en segundos

Compilado en un solo binario. Cero dependencias externas (Ni Node, ni Python).

Si tienes Go instalado:

go install github.com/Cesar0202/docker-doctor@latest

Una vez instalado, el comando `docker-doctor` estará disponible en cualquier terminal.

Descarga Manual (Binarios precompilados)

Descarga el archivo doctor.exe o docker-doctor-linux-amd64 desde los Releases de GitHub y agrégalo a tu PATH.

Hecho con ❤️ para la comunidad DevOps. Cero telemetría, 100% código abierto.
