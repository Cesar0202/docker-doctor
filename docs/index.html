Características Profesionales

Todo lo que necesitas para auditar y administrar tus entornos Docker locales y en servidores.

Health Score Inteligente

Recibe una calificación global de 0-100 basada en un análisis profundo de tus contenedores, volúmenes, imágenes y seguridad.

Asistente de Reparación (Fix)

No memorices comandos de limpieza. Usa docker-doctor fix para que el asistente te guíe de forma interactiva para borrar contenedores y volúmenes basura.

Experto en Errores (Explain)

¿Docker arrojó un error extraño? Usa docker-doctor explain "tu error" y la base de conocimientos te dirá exactamente cómo solucionarlo.

Historial y Tendencias

Lleva un registro temporal de tus escaneos guardados en SQLite local. Observa si tu salud mejora o empeora usando gráficos ASCII en la terminal.

Seguridad Trivy Integrada

Si tienes Trivy instalado, el doctor automáticamente buscará vulnerabilidades CRÍTICAS y ALTAS en tus imágenes Docker en el mismo reporte.

Exportación Múltiple

Soporte nativo para CI/CD exportando reportes detallados en formatos JSON, Markdown o HTML completamente estático.

Dashboard Web en tiempo real

Docker Doctor incluye un servidor web integrado. Sin NodeJS. Sin Python. Un solo binario sirve el Frontend y Backend.

$ docker-doctor web --port 8080
[INFO] Servidor Web iniciado. Abre tu navegador en http://localhost:8080

Instalación y Documentación

Empieza a optimizar tu entorno en segundos. Solo requieres tener Go instalado o descargar los binarios pre-compilados.

1. Instalación Global (Recomendada)

go install github.com/Cesar0202/docker-doctor@latest

2. Comandos Principales

  • docker-doctor scan
    Ejecuta el escaneo de salud principal en la terminal.
  • docker-doctor fix
    Abre el asistente interactivo de limpieza.
  • docker-doctor explain "error"
    Consulta la base de conocimientos sobre un error específico.
  • docker-doctor history --trend
    Muestra el historial y gráfico ASCII de tus escaneos anteriores.
